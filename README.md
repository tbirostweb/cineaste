# Cinéaste

Application de découverte et de gestion de films, développée avec Vue 3 pour l’interface et Symfony pour l’API.

- `web/` : application Vue 3 et Vite.
- `environnement-local/www/html/wr506d/` : API Symfony (REST et GraphQL) et tests.
- `environnement-local/` : configuration de développement local.

Consultez les README de chaque application pour les prérequis et commandes de lancement. Les fichiers de configuration privés, clés JWT et données locales ne sont pas publiés.

Projet présenté par [BirostWeb](https://birostweb.fr).
